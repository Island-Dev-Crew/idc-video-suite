# cut

Read the project lock and every source transcript. Choose the edit mode from the user's brief. For documentary edits preserve chronology, the full story and distinct perspectives. Trim dead air and accidental repeats; retain meaningful tangents in the longform if requested. The short launch can use a separate tighter selection. Last-take-per-line selection applies only to explicitly scripted repeated takes.

Write ordered keepers with source ID, source-relative in/out and a one-line reason. For a multicamera session choose one continuous voice source; align other camera views using observed anchors and mark uncertain stretches. A capture hiccup can require piecewise offsets; a single global offset does not prove sync throughout.

Preserve requested beats such as DHH, the bet, check/diff-caps/seal, the locked Shelf, the room, Omarchy, Forge 50, Uncle Bob and CTA when the recorded story contains them. Attach evidence to factual product claims; personal origin stories can remain with an explicit evidence gap rather than being deleted.

The editor's canonical recipe validator owns keeper bounds and output timing. Read [integration](../../references/editor-integration.md). Keep previews in pending review until the owner's requested keeper gate is met. Speed is 1× unless requested; if 1.25× is authorized, apply once to picture and voice and rebuild output word timing. The current v2 recipe compiler is 1× only: do not describe its output as sped up.

Done when every keeper resolves to a source interval, cut intent is explicit, and the proposed spine is inspectable. Editorial selection and sync judgment are advisory; recipe validation is enforced by the editor.
