# oracle-spec

Read the lock, transcript inventory, keepers and B-roll catalog. Write `edit.spec.md` with title, mode, target duration, ordered spine, source/evidence for each beat, exact hook text, motion approach, captions, audio policy, output variants, risks and known gaps.

Distinguish personal narrative from externally checkable product claims. Unsupported product assertions need evidence, qualification or omission. A listen-along warehouse layout is explicit hook then held image plus essay audio; it is not the documentary default.

Propose one small hook first. Carry prior owner acceptance forward when unchanged. Follow only the review gates the owner has requested; no magic SHIP keyword is required. The current brief overrides inherited channel assumptions and old skill examples.

Done when another editor can map the spec to the proposed timeline and identify unverified claims. This seat produces an advisory plan; it does not render or certify quality.
